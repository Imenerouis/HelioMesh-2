Part 1 — Simulation Temporal Benchmark (6-Area Methodological Audit)

1.1 Data Leakage

PASS
Chronological split performed by array slicing with no shuffling (X[:8400] / X[8400:10200] / X[10200:]). No StandardScaler, no encoder, no imputer fitted across split boundaries. Each sequence is a self-contained 42-feature vector requiring no cross-row statistics. No leakage path exists.

1.2 Future-Information Leakage

PASS
Feature vector contains only the 6 input window steps (t=0…t=25). Horizon gap (t=25…t=55) is simulated after window is fully built; only the binary label is extracted from t=55 — no future feature values enter the input vector. Delta features are intra-window (t5 − t0) only. delta_power_output importance = 0.0 (sail fixed per sequence — confirmed, not a bug).

1.3 Sequence Overlap

PASS
Each of the 12,000 sequences uses independent random initial conditions. No sliding-window extraction from a shared trajectory. Test sequences share no raw state with training sequences. Timestamps are synthetic ordering labels, not a continuous real timeline.

1.4 Target Construction

PASS — disclosed caveat
Target derived from simulated state at t=55 using the same deterministic safety rules as the snapshot classifier. Future state variables never placed in the feature vector. KP dominance (83.3% feature importance) is the main structural property — already disclosed in forecaster_metrics.json with an explicit KP-only baseline.

1.5 Chronological Split

PASS
Train 8,400 / Val 1,800 / Test 1,800. Exact match with reported sizes. No shuffling anywhere. Validation used only for diagnostic reporting — model not retrained or tuned on validation outcomes.

1.6 Baseline Validity

PASS
Both baselines evaluated on the identical test partition. Last-known-state (F1=0.9015) and KP-only threshold (F1=0.8977) are correctly designed. Model improvement is genuine: +6.9pp / +7.3pp macro-F1, +13.7pp / +14.4pp CRITICAL recall. Margins are not marginal.
